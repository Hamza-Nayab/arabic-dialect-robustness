## Fine-tuning (as run for the paper)

* All layers, embeddings and head trained; FP16 autocast + GradScaler; AdamW (wd 0.01), batch 16, max length 128,
  10% warm-up, clip 1.0, at most 4 epochs, best dev macro-F1 epoch restored.
* Learning rate per encoder from {1e-5, 2e-5, 3e-5, 5e-5} on dev (PID, seed 42) -> `selected_lrs/`; reused for every regime,
  seed, learning-curve point, leaky run and v2 run.
* Regimes: PID, PID_weighted, LODO_matched (1,531), MSA_only (1,905), PID_n1531, PID_n1905; seeds 42-46.
* Crash-proof: a run counts as done only if its JSONL line (fsync'ed) and all prediction files (atomic `os.replace`) exist;
  tar backup every 10 runs.
* Executed on Kaggle (2 x T4): original 8 encoders with `kaggle/run_all_gpu.py`; review experiments (3 more encoders,
  5c-5e, LLMs) with `kaggle/run_review_gpu.py` in two kernels (A: encoders, 6.4 h; B: LLMs), imported with
  `python kaggle/import_review_outputs.py <review_outputs_X.tar.gz>`.
* Raw Kaggle downloads are kept unmodified in `kaggle/raw_outputs/` as provenance. Do not publish that folder,
  `hidden_cache/`, `embeddings/`, `embeddings_layers/` or any Kaggle token.

## Deviations from `IMPLEMENTATION_MASTERPLAN.md`

* **Added controls:** `PID_n1531` / `PID_n1905` (stratified pooled training on LODO-/MSA-only-sized subsets), so transfer deltas are not confounded with training-set size.
* **Point estimates and intervals:** all reported numbers are seed means with hierarchical bootstrap intervals of the same mean; majority-vote ensembles are used only for McNemar.
* **Step 7 fixes:** Latin-script detection ignores URLs, @mentions and RT; elongation counts only repeated Arabic letters or tatweel; the sarcasm analysis reports per-class recall, because 294/306 sarcastic test tweets are negative.
* **Mixed model:** the frequentist GLM was replaced by a Bayesian beta-binomial GLMM over all encoders (6c), with priors, sampler settings and diagnostics reported in the paper.
